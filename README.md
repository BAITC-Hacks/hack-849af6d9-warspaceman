## Как запустить

**Backend:**
```bash
cd backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**ML сервис:**
```bash
cd ml
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn service.main:app --reload --port 8100
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev   # http://localhost:5173
```

Переменные окружения — см. `.env.example` в каждой папке (`ML_SERVICE_URL` для backend, `VITE_API_URL` для frontend).

## Формула рейтинга задачи

Балл от 0 до 100, начисляется только за заполненные и подтверждённые поля карточки:

| Показатель | Баллы |
|---|---|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом (контакт + формат) | 10 |

Уровни готовности: **0–39** черновик · **40–69** рабочая · **70–89** готовая · **90–100** приоритетная.
Рейтинг пересчитывается после каждого подтверждённого дополнения карточки.

## Правила каталога

- Все опубликованные (подтверждённые) задачи видны всем командам, независимо от рейтинга — низкий рейтинг не скрывает задачу
- Сортировка по рейтингу, фильтры по теме и уровню готовности
- Любая команда может откликнуться на любую задачу, число откликов не ограничено
- Выбор команды — только вручную представителем бизнеса; автоматическое назначение запрещено
- ИИ может рекомендовать задачи студентам по интересам/навыкам, но не ограничивает общий каталог и не добавляет факты, не указанные пользователем

## Тестовые сценарии

1. **Черновик → карточка**: отправить слабое описание задачи → получить ≥3 уточняющих вопроса → ответить → получить редактируемую карточку с рассчитанным рейтингом
2. **Рост рейтинга**: дополнить карточку одним недостающим полем → подтвердить → убедиться, что рейтинг и уровень готовности пересчитались
3. **Публикация и отклик**: подтверждённая задача появляется в каталоге на позиции по рейтингу → команда подаёт отклик (идея, план, срок, ссылка)
4. **Выбор бизнеса**: несколько откликов на одну задачу → бизнес вручную принимает один и отклоняет остальные
5. **Fallback ИИ**: ML-сервис недоступен → backend использует локальную заглушку, сценарий не падает

Синтетические данные для тестов — 5 черновиков разной полноты, 5 карточек, 5 профилей команд, 5 откликов (см. `docs/` или сид-скрипт, если добавите).
